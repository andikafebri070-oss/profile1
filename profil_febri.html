Tentang Saya

Saya adalah mahasiswa Universitas Muhammadiyah Kalimantan Timur (UMKT) jurusan Teknik Informatika. Saat ini saya sedang mempelajari berbagai hal di bidang teknologi, salah satunya adalah HTML untuk membuat dan mengembangkan halaman web. Saya tertarik untuk terus meningkatkan kemampuan saya dalam bidang pemrograman dan teknologi informasi.

Selain belajar, saya juga suka algoritma pada komputer. Bagi saya, algoritma pada pemerograman sangat menarik dimana saya dapat berkreasi dengan mencurahkan semua ide yang ada didalam kepala saya mau untuk menyelesaikan masalah,ataupun untuk berkreasi, saya ingin terus mengembangkan kemampuan di bidang teknologi sekaligus meningkatkan keterampilan dalam membuat sebuah web dengan ide dari isi kepala saya .
